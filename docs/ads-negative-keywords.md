# 광고 제외 키워드

Google Ads 계정에 넣을 제외 키워드 목록과 그 근거.

**코드가 아니라 계정 설정이다.** 저장소에서 적용할 방법이 없으므로 여기 적어 두고
사람이 Ads UI 에 넣는다. 근거를 같이 남기는 이유는, 목록만 있으면 나중에 "이거 왜
막았지" 를 다시 판단해야 하기 때문이다.

출처: 검색어 보고서 2026-07-30 ~ 08-02.

---

## 먼저, 규모를 정확히 말한다

| | 검색어 | 노출 | 클릭 | 비용 |
|---|---|---|---|---|
| 전체 | 127 | 1,927 | 63 | ₩134,729 |
| 비-US 의도 | 18 | 25 | 1 | ₩2,157 |
| **비중** | | **1.3 %** | **1.6 %** | **1.6 %** |

**이건 큰 문제가 아니다.** 정리할 가치는 있지만 우선순위가 높지 않다.

> **기록해 두는 정정.** 이 작업을 처음 제안할 때 "노출의 12 %, 비용의 35 %" 라고
> 말했다. 그건 첫 번째로 받은 작은 CSV(노출 194)를 기준으로 계산한 값을 전체
> 계정에 그대로 적용한 것이라 과장이었다. 전체 데이터 기준은 위 표다.

## 그리고 낭비의 전부는 한 건이다

비용이 발생한 비-US 질의는 **`hsn code for boulder` 하나뿐**이다 — 클릭 1 회,
₩2,157. 나머지 17 개 질의는 노출만 있고 비용이 0 이다.

즉 **`boulder` 하나만 막아도 측정된 낭비 지출 100 % 가 사라진다.** 나머지는
지출이 아니라 노출 정리이고, 지금 규모에서는 품질평가점수에 의미 있는 영향을
줄 만큼 크지 않다.

## 넣을 목록 (제외 키워드 · 확장검색)

바로 붙여넣을 수 있다. 캠페인 수준에 넣는다.

```
boulder
jav
india
canada
england
查询
```

| 키워드 | 막는 것 | 측정된 영향 |
|---|---|---|
| `boulder` | `hsn code for boulder` | **클릭 1 · ₩2,157** |
| `jav` | `jav hsn code` | 노출 2 |
| `india` | `india tariff calculator` | 노출 1 |
| `canada` | `how much is duty from us to canada`, `usa to canada import fees` | 노출 3 |
| `england` | `import fees from england to us` | 노출 1 |
| `查询` | `hts 查询` | 노출 1 |

`canada` · `england` 는 **미국으로 들어오는** 수입이 아니라 미국에서 나가는
방향의 질의다. 우리 계산기는 US 수입 관세를 다루므로 대상이 아니다.

## `hsn` 은 넣지 않는다 — 판단이 필요한 자리

HSN 은 인도에서 쓰는 용어이고(US 는 HTS), `39211 hsn code` 같은 질의는 인도
사용자로 보인다. 그런데 세 건이 애매하다.

```
hsn code usa      (노출 1)
hsn code for usa  (노출 2)
hsn code in usa   (노출 2)
```

**US 로 수입하려는 사람이 인도식 용어를 쓴 것일 수 있다.** 실제로 인도에서
미국으로 수출하는 쪽이라면 우리 대상에 가깝다.

`hsn` 을 확장검색 제외로 넣으면 이 다섯 노출도 같이 사라진다. 그 다섯이
비용을 쓴 적은 없으므로 **지금은 넣지 않는 쪽을 권한다.** 다시 볼 조건:

- `hsn` 질의에서 클릭이 발생하고 전환이 안 붙을 때
- 또는 `hsn` 노출이 전체의 5 % 를 넘을 때 (지금 1.0 %)

---

## 이걸 한다고 전환이 생기지는 않는다

같은 리포트에서 **63 클릭 · ₩134,729 · 전환 0** 이다. 제외 키워드는 그중
₩2,157 을 되돌린다 — 1.6 % 다.

전환 0 자체는 이 데이터로 판정할 수 없다. 전환율이 3 % 여도 63 클릭에서 0 건이
나올 확률이 14.7 % 이고, 95 % 신뢰 상한은 4.8 % 다. 즉 "퍼널이 고장났다" 는
결론도 "정상이다" 는 결론도 아직 못 낸다.

그래서 순서는 이렇다:

1. 제외 키워드를 넣는다 (5 분, 효과 1.6 %)
2. **다음 광고비가 쌓이기를 기다린다** — 퍼널 계측이 이미 붙어 있으므로 이번에는
   어디서 죽는지 남는다 (`public/analytics.js`, `public.analytics_events`)
3. 그 데이터로 판정한다

1 번은 지금 하고, 판단은 2 번 뒤로 미룬다.
